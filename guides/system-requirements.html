System requirements

Steam lists a fairly demanding spec: an RTX 3060 at minimum and an RTX 3080 recommended. Windows only.

  • OS: 64-bit Windows 10.
  • Minimum CPU: Intel Core i3-7100 / AMD Ryzen 3 1200.
  • Minimum RAM: 8 GB. GPU: NVIDIA RTX 3060.
  • Recommended: Core i7-6700K / Ryzen 7 1700, 16 GB RAM, RTX 3080.
  • Storage: 8 GB.

Other details

Steam lists English with full audio. Controller support is not listed on the store page.
